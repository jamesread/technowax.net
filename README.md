# technowax.net

A community and utility site for people interested in **no-nonsense open source software, self-hosting, and modern technology**.

**Community:** most discussion is on [Discord](https://discord.gg/jhYWWpNJ3v) ([Matrix](https://matrix.to/#/#technowax:matrix.org) too). This dev site mirrors utilities from the live site at [https://technowax.net](https://technowax.net).

Optional config: `DISCORD_INVITE_URL` in `config.ini` (see `src/public_html/config.ini.example`).
